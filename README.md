One word for the whole internet: **feral**.

The internet is wild, untamed and unmoderated — one word that makes a reader
laugh and then nod. `main.ts` writes that single word to `output/entry.txt`,
deterministically, with a guard that refuses anything outside the 1–30
character single-word gate.

## Run

```sh
node main.ts
cat output/entry.txt
```
